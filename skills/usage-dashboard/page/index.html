Method and definitions

Where every figure comes from and what it means.

Sources. A local collector reads the transcripts Claude Code (desktop and terminal) and Cowork keep on this computer, each time the dashboard is refreshed (nightly when scheduled). Claude deletes transcripts after 30 days by default, so the collector keeps a permanent ledger; days whose transcript was gone before the ledger began show sessions and prompts only, drawn hatched on the calendar. Chats on claude.ai are not included.

Tokens. Output tokens include thinking. Input is split into fresh input, cache writes and cache reads; total tokens add all four. A model request is one call to the model, so a single prompt can trigger dozens.

Active hours. The time between consecutive messages in a session, counting gaps of up to 15 minutes. Longer pauses count as a break. Sub-agents run in parallel and are not added on top.

API-equivalent cost. What the same tokens would cost at pay-as-you-go API prices, as a yardstick for how much work was done, not money spent. Each model's price is calibrated from the cost records Claude Code writes into its transcripts; models without such records take their family's rate. It is an estimate, not a bill: a subscription covers this use.

Sub-agents. Agents launched from a session, directly or as steps of a multi-agent workflow. Workflow steps that never called the model are left out. Their output counts toward their parent session.

Sessions. A session that runs past midnight counts on each day it touches, so day tiles can add up to more than the period's total, which counts every session once.

Comparisons. Every change compares the reporting period with the same number of days immediately before it. Weekly series start on Mondays; days follow local time. Lines written count lines in files Claude created or in the replacement text of its edits.
